# HeroesLab

Разрабатываем платформу и сервис для игроков и организаторов по ККИ "Берсерк Герои".

### 🛠 Чем мы занимаемся
* **Турнирный софт:** проводим турниры по швейцарской системе и строим сетки плей-офф.
* **База карт и декбилдер:** помогаем собирать и тестировать колоды.
* **Статистика:** собираем результаты матчей, метагейм и рейтинги.
